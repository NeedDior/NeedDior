## ~/building

### FOC — Fear of Creating

Most people have a project they've always wanted to build and never had the right people
for. FOC is matchmaking for that: side projects and startups, not another social feed.

- **Profiles** — role, skills, mission statement, vibe tags, the kind of project you want, how much time you have, and who you're missing
- **Discovery** — swipe through builder profiles, or browse a filterable grid by skill, project type and availability
- **Matching** — two likes make a match
- **Chat** — a match unlocks a private channel so you can start planning

Coming later: an **AI Code Checker** for finding flaws in your code, an **AI 3D Modeler**
that turns reference images into Blender-ready models, plus group workspaces, real-time
chat and smarter recommendations.

Built for solo founders without a team, programmers who want to work on something they
care about instead of closing tickets, and designers, 3D artists and ML engineers who'd
rather build *with* people than *for* them.

`React` · dark, terminal-styled, built for builders
